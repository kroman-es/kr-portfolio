# Web-KIRA Portfolio

Professional portfolio for **Karelys Román Angarita**, focused on Administrative Management and ISO Quality Standards.

## Project Structure
This project is built as a **Single Page Application (SPA)** to ensure fast loading times and a smooth user experience. It features:
* **Home Section**: Professional summary and core competencies.
* **Experience Section**: Interactive accordion-based career timeline.
* **Portfolio Section**: Specialized view for data analysis and Excel/BI case studies.

## Technical Stack
* **HTML5**: Semantic structure.
* **Tailwind CSS**: Utility-first styling for responsiveness.
* **Custom CSS**: Integrated design system based on Canva aesthetics (Sage Green palette and Cormorant Garamond typography).
* **JavaScript**: Custom logic for view switching and UI interactivity.

## Maintainability
* **Variables**: Global colors and fonts are defined in `style.css` via `:root` variables for easy branding updates.
* **Modularity**: Separation of concerns is maintained with independent HTML, CSS, and JS files.
